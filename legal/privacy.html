Dockingbird by Zeusfyi

Privacy Note

Dockingbird sends Zeusfyi only the minimum metadata required for licensing and package downloads. Nothing from your repositories or agents is ever sent: no source code, file paths, branch names, commits, repository names, prompts, agent messages, agent outputs, AI provider credentials or API keys, or environment variables.

What is sent to license.zeus.fyi

Data Description When sent
Computer ID Keyed hash of your machine identifier (scoped per product; never the raw machine ID), or a random local ID when no machine ID is available license activate, license trial, check-ins
Computer label Hostname (truncated to 64 chars) or custom --label value for license activations license activate, license trial
Product & client versions dockingbird version and zeusfyi-license version license activate, license trial, check-ins
Heartbeat counter Incrementing counter used to detect cloned activations Check-ins
Request key Random per-request idempotency token Every licensing request
License key Checked against a stored hash (the plaintext key is not stored by Zeusfyi) license activate, license activations, initial package-index install
Signed license document Signed lease token identifying the license, activation, plan, and dates Check-ins, license deactivate
Download token Activation credential for Zeusfyi's package index dockingbird update, update --check on index installs

Like any HTTPS service, Cloudflare (which hosts license.zeus.fyi) sees the requesting IP address to route traffic and enforce rate limits.

Retention

  • Activations remain active until released via dockingbird license deactivate, dockingbird license activations --release, idle expiration, or revocation.
  • License keys are stored only as cryptographic hashes and cannot be read back in plaintext.
  • Request keys are purged automatically after their short retry window.

Contact & Deletion Requests

To ask questions or request access or deletion of licensing records associated with your license, email privacy@zeus.fyi.
